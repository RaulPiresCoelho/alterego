Windows · release notes

Before you install

  • Alter Ego installs on its own, and needs no agent harness to do it. Agents backed by Claude Code need it installed in order to run, and other harnesses are supported through adapters. On Windows, install Claude Code by running irm https://claude.ai/install.ps1 | iex in PowerShell. The Claude desktop app is a different product and does not provide it. If its installer says .local\bin is not on your PATH, that does not matter to Alter Ego, which finds Claude Code there by itself.
  • This pilot build is unsigned, so Windows is cautious about it. In Edge, the download is held as “isn't commonly downloaded”: open Downloads, choose … → Keep, then Show more → Keep anyway. If Windows then shows “Windows protected your PC,” click More info → Run anyway.

What it does

  • Double-click to install — no admin, no configuration.
  • On first run it helps you bring your existing agents into one workspace.
  • Uninstalling removes the product and leaves your workspace untouched.
